# AIXX — CodeBuddy / WorkBuddy 插件市场

> Google for AI — One line. Every AI model.

一个 API Key，调用全世界的 AI：**38+ 大模型**(Claude / GPT / Gemini / DeepSeek / Qwen / GLM 等) + **AI 出图** + **AI 视频**，完全 OpenAI 兼容。

## 一键安装

在 CodeBuddy / WorkBuddy 对话框里输入：

```
/plugin marketplace add https://github.com/aixx001/aixx-workbuddy-marketplace.git
/plugin install aixx@aixx-plugins
/reload-plugins
```

安装时填入你的 **AIXX_API_KEY**（没有就去 https://baodan.run/console/ 注册，送 ¥5，登录后「令牌」页生成）。
